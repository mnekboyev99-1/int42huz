# Int42h

<h3 align="center">Ta'lim jarayonini boshqarish va sifatli ta'lim olish uchun zamonaviy platforma</h3>

## 🚀 Loyiha Haqida

Int42h — o'qituvchilar va o'quvchilar uchun qulay, interaktiv va keng ko'lamli imkoniyatlarga ega bo'lgan ta'lim platformasi. Ushbu tizim orqali onlayn darslarni tashkil etish, o'quv materiallarini ulashish, o'zlashtirishni nazorat qilish hamda darslarni zamonaviy interaktiv usullarda o'tish jarayonlari sezilarli darajada osonlashadi. 

Loyiha hakamlar hay'ati ko'rib chiqishi uchun taqdim etilmoqda va tizimning barcha imkoniyatlarini batafsil yoritib berishni maqsad qilgan.

## 🌟 Asosiy Imkoniyatlar

- 📖 **Kurslar** — Interaktiv darslar yaratish va ularni qulay boshqarish imkoniyati.
- ✏️ **Zamonaviy Muharrir** — Bloklarga asoslangan qulay matn va media tahrirlagich.
- 📝 **Vazifalar** — O'quvchilarga topshiriqlar berish va natijalarni tekshirish.
- 📊 **Tahliliy Ma'lumotlar (Analytics)** — O'quvchilar faolligini va kurslar samaradorligini kuzatish.
- 🧠 **AI Yordamchisi** — O'rganish va o'rgatish jarayonlarida aqlli sun'iy intellekt yordami.
- 👥 **Guruhlar va Rollar** — Foydalanuvchilarni guruhlarga ajratish hamda ularning ruxsatlarini boshqarish.
- 🎨 **Moslashuvchan Dizayn** — Tizim ko'rinishini va brendingni o'zlashtirish.

## 🛠️ Texnologiyalar (Tech Stack)

Loyiha quyidagi zamonaviy va xavfsiz texnologiyalar asosida mustahkam arxitektura yordamida qurilgan:
- **Frontend (Taqdim etilayotgan qism):** Next.js, React, TailwindCSS, TypeScript
- **Backend:** FastAPI, Python, PostgreSQL, Redis
- **Infratuzilma:** Docker

## 🚀 Ishga Tushirish

Loyihaning frontend (veb interfeys) qismini lokal muhitda ishga tushirish uchun:

```bash
git clone https://github.com/mnekboyev99-1/int42huz.git
cd int42huz/apps/web
npm install   # yoki yarn install / bun install
npm run dev
```

Platforma sozlamalari va arxitekturasi ishlab chiquvchilar jamoasi tomonidan to'liq sozlangan va ishlashga tayyor holatda. Barcha interfeys va vizual qismlar `apps/web` papkasida joylashgan.
